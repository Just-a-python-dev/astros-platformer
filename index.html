Управление

[ A ] / [ D ]
Движение влево и вправо.
[ SPACE ]
Прыжок — только стоя на платформе.
[ ESC ]
Пауза / снятие паузы.
[ R ] на паузе
Перезапуск с подтверждением.
Весь прогресс сбрасывается.

Босс — зелёный инопланетянин

👾
5 HP у босса
Каждый прыжок на босса снимает 1 HP.
⚡
Лазерная атака
Каждые ~1.5 секунды босс стреляет лазером.
🚀
Победа — ракета
При победе босса появляется рокета.

Как погибнуть

⬇️
Падение в пропасть
Упал за нижний край экрана — теряешь одну жизнь. Игрок появляется заново.
🗡️
Шипы
Касание — теряешь жизнь. Игрок появляется заново.
🔴
Лазер босса
Задела — мгновенный Game Over без шанса на возрождение.

Python-игра, работает на Windows и macOS

⊞
Windows
Python 3 · pygame · pygame-menu

Иконка astros_windows.ico подхватывается автоматически. Протестировано на Windows 10 и 11, AMD и Intel.

Windows 10 / 11 (64-bit)
Разрешение 800 × 600 и выше
Клавиатура: A, D, SPACE, ESC, R

Portable · exe · просто открой и играй


macOS
Python 3 · pygame · pygame-menu

Иконка astros_macos.icns подхватывается автоматически. Протестировано на macOS 13 Ventura и новее, Apple Silicon и Intel.

macOS 13 Ventura или новее
Apple Silicon M1–M4 или Intel
Клавиатура: A, D, SPACE, ESC, R

Образ диска · dmg · открой и перетащи в Applications
